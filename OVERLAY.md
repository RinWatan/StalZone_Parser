# Оверлей STALZONE

Запустите `dist/STALZONE-overlay.exe`. Локальный `exbo.json` должен лежать
рядом с EXE. Старая сборка `dist/STALZONE.exe` остаётся отдельным файлом.

- При запуске появляется компактная панель поверх окон. Перемещайте её за
  системный заголовок; размер меняется за края окна.
- «Прогон» ищет сделки по каталогу аукциона, с бюджетом из полного интерфейса.
- «Развернуть» открывает все вкладки. «Свернуть в оверлей» возвращает панель.
  Анализ продолжает работать; результаты и выбранная вкладка сохраняются.
- В панели видны до пяти лучших сделок. «Лот» — цена одной пачки,
  «Прибыль» — расчётный плюс для всего рекомендуемого количества этой строки.
  Двойной щелчок копирует название предмета.
- Ctrl+Shift+Space скрывает и возвращает окно, не останавливая анализ.
  Для одновременной работы двух копий горячая клавиша доступна только одной;
  вторая сообщает о конфликте и может сворачиваться через панель задач.
- «Стоп» останавливает анализ после завершения текущих запросов.
- Крестик закрывает приложение. Настройки положения сохраняются локально.

Оверлей рассчитан на безрамочный режим игры. Он получает клики внутри
своего окна. Для возвращения управления игре нажмите на неё или скройте
оверлей горячей клавишей. При восстановлении окна за пределами основного
экрана положение ограничивается его рабочей областью.

Сборка: установите PyInstaller (`python -m pip install pyinstaller`),
затем запустите `build_overlay.bat`. Ключ не включается в сборку.
Тесты: `python -m unittest discover -s tests -v` (Windows с рабочим Tk).
