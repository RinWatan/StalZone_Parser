# Оверлей STALZONE с картой

Запуск: `dist/STALZONE-map-overlay.exe`. Локальный `exbo.json` должен лежать
рядом с EXE; ключ не включается в сборку и исключён из Git. Старые EXE
`STALZONE.exe`, `STALZONE-overlay.exe` и `STALZONE-hud.exe` остаются отдельными файлами.
Для этой версии нужен установленный Microsoft Edge WebView2 Runtime.

- Игра должна работать в безрамочном режиме через лаунчер EXBO.
- По умолчанию над игрой отображается компактная панель; клики проходят в игру.
  При Alt+Tab панель скрывается и появляется при возвращении в игру.
- `F10` включает управление панелью. Повторное нажатие или `Esc`
  сворачивает её и возвращает управление игре. То же делает «В игру».
  Следующее включение управления возвращает последний выбранный режим:
  полный после «Развернуть», компактный после «Свернуть». Esc и Alt+Tab
  этот выбор не сбрасывают. Новый запуск приложения начинается компактно.
- «Развернуть» открывает полный интерфейс, «Свернуть» возвращает компактную
  панель в режиме управления. Перетаскивайте её за надпись STALZONE; размер
  полного окна можно менять за края. Положение и размеры сохраняются локально.
- «Карта» в компактной панели сразу открывает вкладку интерактивной карты.
  Доступны шесть локаций, масштабирование, поиск, фильтры слоёв и свои метки.
  Укажите название, нажмите «Ставить» и щёлкните по карте. Своя метка удаляется
  щелчком с подтверждением. Они хранятся в локальном `wiki_marks.json`.
- Сворачивание не перезагружает карту: выбранная вкладка, масштаб, слои,
  результаты анализа и работающий прогон сохраняются в одном окне pywebview.
- «Прогон» в панели ищет сделки выкупа с бюджетом из полного интерфейса.
  Показаны пять строк с наибольшей расчётной прибылью: «Лот» — цена одной
  пачки, «Прибыль» — плюс для всего рекомендуемого количества данной строки.
- «Стоп» завершает анализ после текущих запросов. Крестик закрывает приложение.
- Без запущенной игры открывается компактное окно для настройки. Если горячая
  клавиша занята другой копией, новая копия сообщает об этом и закрывается.

Карта получает данные, изображения и Leaflet через интернет; при ошибке
загрузки отображается сообщение, повторите запрос кнопкой локации.
Оверлей следует клиентской области окна игры, без изменения файлов игры.

Сборка: `build_overlay.bat` (Python 3.13, PyInstaller, pywebview, httpx).
Тесты: `python -m unittest discover -s tests -v`.
Проверки настоящего окна (Windows, WebView2, интернет; закрыть другие копии):
`python tests/check_webview_hud.py`, затем `python tests/check_packaged_hud.py`.
Первая использует временный файл меток и сохраняет снимок в `build/`;
вторая проверяет собранный EXE и закрывает проверочную копию.
Ветка интеграции: `codex/map-overlay`.
