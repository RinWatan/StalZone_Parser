# Статистика цен во вкладке Аукцион

Одобрено пользователем: до 100 последних продаж в пределах 7 дней.
Отдельная ветка codex/auction-price-statistics, без объединения в main.

1. Тестами закрепить границы периода, сортировку по времени, цену за штуку,
   отсутствие продаж, фильтрацию редкости/заточки и пагинацию истории.
2. В stalzone_agent.py хранить исходные страницы истории выбранного предмета.
   Догружать страницы по необходимости для текущего фильтра. Исключать записи
   с неверным временем, неположительной ценой/количеством и будущим временем.
   Средняя арифметическая и медиана: одна завершённая продажа = одно наблюдение
   price/amount. Максимум 100 наблюдений за 7 дней. Защитный предел 50 страниц
   явно обозначать как неполную выборку.
3. В stalzone_gui.py добавить сводку над таблицей, одинаковую для текущих лотов
   и истории. При смене фильтра пересчитывать. Показывать количество сделок,
   цену за штуку, малую выборку (<5) и пустую историю. Скрывать старую сводку
   во время загрузки другого предмета или при ошибке.
4. Проверить unit-тесты, UI в WebView2, собрать отдельный EXE без API-ключа.
   Зафиксировать изменения только в рабочей ветке для проверки пользователем.
