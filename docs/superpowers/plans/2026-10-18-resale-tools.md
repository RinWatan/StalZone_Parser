# Характеристики, фильтры и объяснение перепродажи

**Goal:** согласованный первый этап бесплатных возможностей SZ: понятные
характеристики лота, локальные фильтры/наборы и объяснение оценки.
**Architecture:** нормализованная публичная метаинформация идёт через Candidate
в Feed; чистые функции stalzone_resale отвечают за фильтры и объяснение.
Bridge хранит локальные настройки/пресеты, UI открывает карточку Подробнее.
**Tech:** Python3.13, pywebview/WebView2, существующая Free-лента/EXBO.

Ограничения: codex/resale-tools от c89d3b1; main не объединять. Ключ exbo.json
не выводить/не включать в Git или EXE. Новых источников Premium/авторизации нет.
Графики и архив — следующий этап, в этот объём не входят; охоту не возвращать.

1. [x] TDD: нормализация характеристик/неизвестных данных, расчёт комиссии,
   фильтры категории/редкости/заточки/изученности/названий, старые настройки,
   локальные именованные наборы, характеристики никогда не подменяют
   фактическую точность сопоставления EXBO.
2. [x] stalzone_resale.py: ограниченная метаинформация SZ; чистая проверка
   фильтров и формирование карточки. Отсутствующее поле явно неизвестно.
   Пресеты максимум20, имя<=60, все значения валидируются, локальный JSON.
3. [x] Tracker сохраняет category, explored, charge, бонусы, выбранную статистику;
   Verifier передаёт минимум цены за штуку и число более дешёвых предложений
   того же варианта в проверенной выборке. Это не доказательство тождественных
   случайных характеристик. Свежесть EXBO45с остаётся прежней.
4. [x] Bridge и UI: действуют старые min_profit/min_roi и новые поля; основные
   фильтры сверху, расширенные — раскрывающаяся панель; сохранение/загрузка/
   удаление собственных наборов. Кнопка Подробнее отдельно от поиска в игре.
   Карточка показывает формулу/характеристики/данные/конкурентов/ограничения;
   обновляется локально при poll, закрытие по Esc не должно отправлять игру
   в пассивный режим, пока открыта карточка.
5. [x] Полные unit-тесты, реальный WebView2: переключение пресета во время
   ленты, Подробнее, неизвестные характеристики, безопасный вывод текста,
   компактный режим, Стоп. Ревью, отдельный EXE и push только новой ветки.

Проверки:107 unittest-тестов, check_tracker_ui.py и check_resale_tools_ui.py
в настоящем WebView2. Свежий Free-снимок:40 строк,36 нормализованы,20 с
базовыми характеристиками,14 с бонусами. Ревью выявило старый статус наличия
в карточке при паузе репортера; исправлено с воспроизведением тестом до фикса.
Тестовая сборка STALZONE-resale-tools.exe, ключ в архив не включается.
