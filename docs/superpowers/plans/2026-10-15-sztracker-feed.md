# Быстрая лента кандидатов SZ Tracker

Пользователь согласовал: получать кандидатов из бесплатной ленты вместо
полного обхода; цену и наличие проверять через официальный EXBO API.
Ветка codex/sztracker-feed создана от проверяемой версии с картой Лунара
и без охоты. Main не объединять без отдельного разрешения.

1. `stalzone_tracker.py`: нормализация snapshot/lots_update, явные псевдонимы
   известных предметов (Протоартефакт → dm6l2), проверка цен/количества/ID,
   дедупликация, ограниченная очередь по ожидаемому плюсу. Приоритет — только
   подсказка трекера, финальную прибыль вычисляет EXBO. Без скачивания каталога
   на 150 МБ и без обращений к Premium или авторизации SZ Tracker.
2. Проверять только поступившие предметы: актуальные лоты (до 800), совпадение
   цены пачки/количества/редкости/заточки, история 200 продаж с кешем 120 секунд.
   Использовать существующий find_flips без записи в его глобальный кеш лотов.
   Сохранять комиссию, ликвидность, конкурентов, бюджет и надёжность.
3. Один поток получает WebSocket, существующий рабочий поток проверяет очередь.
   Ограничить память и очередь, повторные события не порождают повторный обход.
   Подтверждённые позиции перепроверять через 20с, убирать через 45с без проверки.
   При обрыве/устаревшем источнике очищать показ, переподключаться с паузой.
   Не переключаться молча на полный скан. Остановка закрывает ленту.
4. Кнопка «Лента SZ Tracker» рядом с полным прогоном и в компактном режиме.
   Статус соединения, число полученных/проверенных предметов и очередь; строки
   отмечать временем проверки EXBO. Общий Стоп останавливает активный режим.
5. TDD: схемы/повторы/неверные значения/бюджет, отсутствие лота, цена трекера не
   влияет на EXBO-оценку, кеш истории, нет полного каталога, TTL, обрыв и стоп.
   Настоящий WebView2, короткая проверка Free + EXBO, независимое ревью,
   отдельный EXE с websocket-client. Не публиковать ключ exbo.json.

Ограничения: это недокументированный интерфейс SZ Tracker, его протокол может
измениться. Free имеет собственную задержку/полноту; сверка подтверждает
совпадающее текущее предложение, а не тождество uniqueId сайта и EXBO.
